# Migrate kornia_moons from nbdev to a standard package structure

**Date:** 2026-08-07
**Status:** Approved

## Goal

Replace the nbdev notebook-first workflow with a conventional Python package
layout, while keeping the documentation site with its executed visualizations
(LAF plots, match drawings) published at https://ducha-aiki.github.io/kornia_moons/.

## Decisions (agreed with maintainer)

- **Docs tooling:** MkDocs Material + mkdocs-jupyter + mkdocstrings.
- **Testing:** pytest suite extracted from notebook assertion cells, plus a
  CI smoke-run of the docs notebooks (nbmake) so examples cannot rot.
- **Layout:** flat layout — `kornia_moons/` package stays at repo root.
- **`kornia_moons/line.py`:** stays an untracked WIP file; the migration does
  not touch it.

## Target layout

```
kornia_moons/
├─ pyproject.toml
├─ README.md                # hand-maintained from now on
├─ mkdocs.yml
├─ kornia_moons/
│  ├─ __init__.py           # holds __version__ (single source)
│  ├─ feature.py            # nbdev markers stripped, code unchanged
│  └─ viz.py                # nbdev markers stripped, code unchanged
├─ tests/
│  ├─ test_feature.py
│  └─ test_viz.py
├─ docs/
│  ├─ index.md              # derived from index.ipynb
│  ├─ feature.ipynb         # moved from root, executed outputs committed
│  ├─ viz.ipynb             # moved from root, executed outputs committed
│  └─ api.md                # mkdocstrings API reference
├─ data/                    # sample images used by notebooks and tests
└─ .github/workflows/
   ├─ test.yaml             # pytest + nbmake
   └─ deploy.yaml           # mkdocs gh-deploy
```

## 1. Packaging

- Replace `settings.ini` + `setup.py` with `pyproject.toml`
  (setuptools backend).
- Metadata carried over from `settings.ini` (author, license Apache-2.0,
  description, keywords, URLs).
- Version single-sourced from `kornia_moons/__init__.py` via setuptools
  dynamic metadata; normalized to PEP 440: `0.2.10.dev0`.
- `requires-python = ">=3.9"` (current kornia/torch no longer support 3.7).
- Runtime deps unchanged: `kornia`, `torch`, `matplotlib`, `opencv-python`.
- `[project.optional-dependencies] dev`: `pytest`, `nbmake`, `mkdocs-material`,
  `mkdocs-jupyter`, `mkdocstrings[python]`.
- Release process becomes standard `python -m build` + `twine upload`.

## 2. Source modules

- `kornia_moons/feature.py` and `kornia_moons/viz.py`: remove the
  `# AUTOGENERATED!` headers and `# %%` cell markers; **no semantic changes**.
- Delete nbdev machinery: `kornia_moons/_modidx.py`, `kornia_moons/_nbdev.py`.
- `__init__.py` keeps `__version__` (bumped to the PEP 440 form).

## 3. Tests

- `tests/test_feature.py`, `tests/test_viz.py`: assertions extracted from the
  notebooks' test cells, converted to pytest functions.
- Viz tests force the matplotlib `Agg` backend (no display in CI).
- Tests use the existing `data/` images.

## 4. Documentation

- `mkdocs.yml`: Material theme, explicit nav (index, feature, viz, API).
- `feature.ipynb` and `viz.ipynb` move to `docs/` with executed outputs
  committed; mkdocs-jupyter renders stored outputs (`execute: false`) so doc
  builds are fast and deterministic.
- `docs/index.md` derived from `index.ipynb`; `README.md` becomes
  hand-maintained (same content, minus the AUTOGENERATED warning).
- `docs/api.md` renders the API reference from docstrings via mkdocstrings.
- Site continues to publish to https://ducha-aiki.github.io/kornia_moons/ via
  `mkdocs gh-deploy` (gh-pages branch).
- Notebook image paths updated for their new location relative to `data/`.

## 5. CI

- `test.yaml`: checkout → setup Python → `pip install -e .[dev]` →
  `pytest` → `pytest --nbmake docs/*.ipynb` (smoke-run of docs examples).
- `deploy.yaml`: on push to master → build and deploy the MkDocs site.
- Both replace the current `fastai/workflows` composite actions.

## 6. Cleanup

Delete nbdev/fastai artifacts (tracked): `nbdev.yml`, `_quarto.yml`,
`sidebar.yml`, `docker-compose.yml`, `.devcontainer.json`, `styles.css`,
`MANIFEST.in`, `settings.ini`, `setup.py`, root `index.ipynb`/`feature.ipynb`/
`viz.ipynb` (moved into `docs/`).

Extend `.gitignore`: `token`, `build/`, `dist/`, `*.egg-info`, `_proc/`,
`__pycache__/`, `.ipynb_checkpoints/`, `_docs/`.

Remove untracked build junk locally: `_proc/`, `build/`, `dist/`,
`kornia_moons.egg-info/`, `index_files/`, `CHANGELOG.bak`.

Update `CONTRIBUTING.md` (drop nbdev hooks/notebook instructions) and
`CLAUDE.md` (new commands and structure).

**Note:** the untracked `token` file at repo root appears to be a credential.
It is never committed; `.gitignore` gains an entry to keep it that way.

## Risks & mitigations

- **Behavior drift while stripping markers** — mitigated by making zero
  semantic changes and running the new pytest suite plus notebook smoke-run
  before and after.
- **Docs regressions** — notebooks keep their committed outputs, so the
  rendered site shows the same visualizations as today; deploy is verified
  with a local `mkdocs build` before switching CI.

## Out of scope

- `kornia_moons/line.py` / `LineFeature` (WIP, untracked).
- Any API or behavior changes to `feature.py` / `viz.py`.
- PyPI release automation.
